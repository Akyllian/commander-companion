# R4 Impara Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Impara placeholder with an offline Italian manual: an editorial index of four paths (26 lessons), local search, lesson pages with static diagrams and in-lesson scenarios, a glossary, and the D-021 quick reference as a page. The R1 bridge and `RulesDialog` are removed.

**Architecture:**
- **Content as typed data** in `src/learn/content/*.ts`, bundled with the build: paths, lessons, scenarios and glossary. Thresholds come from the domain constants (`src/game/game.ts`, `src/decks/hand.ts`), never typed as numbers.
- **Pure logic** in `src/learn/*.ts` at 100% coverage: routes, search (normalise, synonyms, rank, excerpt), lesson neighbours. Content integrity is enforced by tests.
- **Views** in `src/learn/ui/`, covered by component tests outside the 100% glob: index, lesson, scenario, diagrams, reference, glossary, not found.
- **Addresses:** `#impara/…` sub-paths in the hash, like Mazzi. Opening a page pushes one entry; changing the path filter replaces it; search is local state.
- **No network, no storage:** nothing is fetched, cached or saved; scenario answers live only in component state.

**Tech Stack:** React 19, TypeScript 7, CSS, Vitest, Testing Library, fast-check

**Spec:** `docs/superpowers/specs/2026-10-23-r4-learn-design.md`, with the corpus `docs/superpowers/specs/2026-10-23-r4-learn-content.md` and the board `docs/art-direction/r4-learn-board.svg`. All 15 decisions of §18 were approved by the product owner on 2026-10-23. Kept unchanged: D-021 copy, D-024, D-025, D-037, D-038, D-040.

## Global Constraints

- **Copy:** Italian, the corpus's exact strings. Claude corrects only rule numbers, effective date, official terminology and factual errors, logging each one (spec §10). A correction that changes a scenario's answer, the meaning of a text, the architecture or the scope stops the work and goes to ChatGPT and the product owner.
- **No cards, no art:** no real card names, rules text or images in lessons and scenarios; no illustrations; diagrams are line drawings with an adjacent text equivalent (spec §2.2).
- **No gamification:** no scores, badges, streaks, percentages, completion state or difficulty labels; nothing about the reader is stored.
- **Offline:** the whole section is static and part of the PWA build. No requests, no IndexedDB, no skeletons.
- **Thresholds:** 40, 0, 10, 21, `{2}` and 7 come from `STARTING_LIFE`, `LIFE_DEFEAT_LIMIT`, `POISON_LIMIT`, `COMMANDER_DAMAGE_LIMIT`, `COMMANDER_TAX_STEP` and `HAND_SIZE`.
- **Targets:** every control at least 44×44 px; lesson rows at least 64 px (`--learn-row-min-height`); scenario answers at least 52 px.
- **Measures:**

  | Token | Value |
  | --- | --- |
  | `--learn-reading-width` | 68ch |
  | `--learn-index-width` | 76rem |
  | `--learn-rail-width` | 16rem |
  | `--learn-row-min-height` | 64px |
  | `--learn-diagram-stroke` | 1.5px |
  | `--duration-learn-page` | 180ms |
- **Motion (spec §13):**

  | Event | Duration | Properties |
  | --- | --- | --- |
  | Open a lesson | 180ms (`--duration-learn-page`) | opacity, ≤ 6px translateX |
  | Back to the index | 140ms (`--duration-fast`) | opacity |
  | Path filter | 140ms | local crossfade, geometry immediate |
  | Search results | 140ms | opacity, no stagger |
  | Glossary disclosure | 140ms | opacity, 2px settle |
  | Scenario check | 140ms | border and outcome opacity |

  Diagrams, arrows, mana and the stack never animate. Reduced motion makes all of it immediate without delaying focus or announcements.
- **Colour:** gold for structure and selection, teal for orientation, red only for real errors. No colour per path or per answer; outcomes are text.
- **Dependencies and scope:** no new dependencies; no new routes outside `#impara`; Partita, Mazzi and Altro unchanged apart from removing the Rules bridge.

## Review Focus

1. **An old or malformed link** (`#impara/basi/slug-sparito`, `#impara/xyz`, `#impara/basi/%E0`). It shows «Questa pagina non è nel manuale» with both actions, never a crash or a silent redirect. Pinned in Tasks 3 and 8.
2. **History after filters and search.** Four filter changes and one Back leave Impara; a search, then a result, then Back returns to the index with the search cleared. Pinned in Tasks 3 and 5.
3. **Search input the reader actually types:** accents and capitals («priorità», «PRIORITA»), typographic apostrophes, English terms («hexproof», «board wipe», «commander tax»), rule numbers («903.8»), one character, only spaces. Pinned in Task 4.
4. **Scenario state across navigation.** Moving to the next lesson starts its scenario fresh; changing an answer before «Verifica risposta» reveals nothing; «Verifica risposta» is disabled until a choice is made; «Riprova» resets the choice and returns focus to the first option. Pinned in Task 7.
5. **Short landscape and zoom** (844×330, 200%). One vertical scroll only, no sticky lesson header, diagrams reflow or scroll sideways with their text first. Pinned in Task 9.

## Findings from the first reading (for ChatGPT before Task 1 is closed)

These came from reading the corpus against the rules as I know them. Task 1 confirms each one against the current official sources.

- **F1 · Direct correction (M05):** after a player casts a spell or activates an ability, **that player** receives priority, not the active player (rule 117.3c). After a resolution it is the active player (117.3b). The text changes from «il giocatore attivo riceve priorità» to «chi l'ha lanciata o attivata riceve di nuovo priorità».
- **F2 · Direct correction (M07):** «Segnalini con nomi diversi non si annullano automaticamente» has one exception: +1/+1 and −1/−1 counters are removed in pairs (704.5q). The proposal adds «salvo +1/+1 e −1/−1, che si annullano a coppie».
- **F3 · To escalate if confirmed (T02, S11, R3):** in multiplayer the first mulligan is free (103.5c). That changes T02's procedure text, S11's «Mulligan» feedback («mettere una carta in fondo»), and R3's Mano di prova, which today puts one card at the bottom after the first mulligan. If Task 1 confirms it, the copy goes back to ChatGPT, and the R3 engine change is a separate decision for the product owner.
- **F4 · Design question (B04 diagram):** spec §2.2 asks for six stops, and the board's six mix Italian and English («STAP, MANT., PESCA, MAIN, LOTTA, FINE»), with no second main phase. B04 describes five phases. Proposal: five Italian stops that match the text — «Inizio · Prima principale · Combattimento · Seconda principale · Fine» — with the three steps of Inizio (STAP, mantenimento, acquisizione) written under the first stop.
- **F5 · Design question (index meta):** spec §4.3 gives both `Lettura · N min` / `Scenario · N min` and the text `Include scenario`; the board shows «Include scenario · 7 min». Proposal: `Lettura · N min`, and `Lettura · N min · Include scenario` for lessons with a scenario.
- **F6 · Design question (path filter control):** the spec defines the filter routes but not the control. Proposal: the second `nav` «Percorsi di Impara» holds five links (Tutti, Le basi, Meccaniche, Interazioni, Al tavolo) with `aria-current`; each group heading also has «Apri il percorso».
- **F7 · Design question (inline glossary, §6.3 «può»):** proposal — no inline glossary disclosures in R4. Each glossary entry links to its lesson, and the manifest keywords feed search. This avoids adding markup to the approved body text.
- **F8 · Design question (which diagrams):** proposal — four diagrams: zones (B02), turn line (B04), combat (B05) and stack (M05). The scenarios have none.
- **F9 · Housekeeping:** the spec and corpus headers end lines with two spaces, which `git diff --check` reports. They become `\` line breaks, as in R3, with no change to the text.
